# 03 — Troubleshooting & FAQ (AMV AI STUDIO / MCP / MasterPy)

## 1. Problemi di connessione MCP
Problema:
- Claude Desktop: stato “Error” invece di “Running”
- Codex: non riesce a connettersi al server MCP

Soluzione:
- Controllare il percorso assegnato a MasterSAIBridge
- Riavvia l'app Claude o Codex

## 2. Problemi di esecuzione script
Problema:
- “L’AI non riesce a eseguire lo script”

Soluzione:
- MasterSap deve essere in esecuzione e avere un progetto aperto
- Controlla in MasterSap se la funzione MasterPy è attiva

## 3. Errori nello script (qualità/robustezza)
Non troverai qui una soluzione.
Rivolgiti al repository MasterSap_Python_Scripts

https://github.com/AMV-Team/MasterSap_Python_Scripts

## 4. FAQ rapide

- Devo avviare MasterSAIBridge a mano?

   No: viene avviato dal client AI al momento della connessione

- Dove finisce lo script?

   Nella cartella dei Documenti utente, nome di default: ms.py

- Posso usare solo uno dei due client?

   Si: Claude o Codex, sezioni indipendenti
